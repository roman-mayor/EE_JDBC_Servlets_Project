Данный мини-проект создан для:
1) Получения опыта по созданию простейшего Enterprise приложения на java;
2) Получения опыта написания собственных классов-сервлетов, использования redirect and forward;
3) Получения опыта работы с GIT and GitHub;
4) Получения опыта работы с JDBC и СУБД PostgreSQL (Driver, connection, statement, resultSet);
5) Получения опыта в работе с Maven and Apache TomCat Server (сборка проекта, конфигурация и запуск локального сервера).
